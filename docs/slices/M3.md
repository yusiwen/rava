# M3 slice detail — dynamic code

Per-slice record for M3. `PROJECT.md` § Slices owns the status and the one-line
description; this file owns what landed, where it stops and the evidence. The checks every
entry closed with are in the [gate baseline](README.md).

## M3.1 — Generated-class definition: verify every `Code` method before insertion; decode switches and `wide` — 2026-11-25

**Acceptance.** `cargo test -p rava-cli --test c2_generated` — exit 0 (5 tests).

**Delivered.**
- `ClassTable::define_class` verifies every `Code` method after parsing and duplicate checks, before insertion; a failure leaves the table unchanged.
- The verifier decodes `tableswitch`/`lookupswitch` and `wide`; the interpreter decodes the same `wide` forms.

**Boundary.**
- `ret` and the other modified opcodes stay unsupported.

See [`dynamic-code.md`](../explanation/dynamic-code.md).

## M3.2 — `java.lang.reflect.Proxy` / `InvocationHandler`, generated proxy classes and default-method dispatch — 2026-11-25

**Acceptance.** `cargo test -p rava-cli --test c2_proxy` — exit 0 (3 tests).

**Delivered.**
- A proxy is a real generated class (`rava/proxy/$ProxyN`) defined through `Shared::define_class`, so every generated method is verified.
- Generated methods box their arguments, call `InvocationHandler.invoke` with a resolved `Method`, and unbox the result; `invokeDefault` re-enters the interpreter.
- `Proxy` natives cover the constructor, `newProxyInstance`, a cached `getProxyClass`, `isProxyClass` and `getInvocationHandler`.

**Boundary.**
- No access checks and no exception wrapping; the `ClassLoader` argument is ignored.

See [`dynamic-code.md`](../explanation/dynamic-code.md).

## M3.3 — `ClassLoader` hierarchy, `defineClass`, loader-aware `Class.forName` and `getClassLoader` — 2026-11-25

**Acceptance.** `cargo test -p rava-cli --test c2_classloader` — exit 0 (4 tests).

**Delivered.**
- One `java.lang.ClassLoader` object per `LoaderId`; a user subclass instance is a real child loader.
- All three `defineClass` overloads, parent-first `loadClass`, `findLoadedClass`, `resolveClass` and loader-aware `Class.forName`.

**Boundary.**
- Resources, packages, modules and access checks remain M4/M5.

See [`class-loading-and-libraries.md`](../explanation/class-loading-and-libraries.md).

## M3.4 — `MethodHandles.Lookup`, `MethodType`/`MethodHandle`, `Lookup.defineClass` — 2026-11-25

## M3.5 — `Unsafe` U0, VM-installed static reflection, direct buffers and the U0 call log — 2026-11-25

**Acceptance.** `cargo test -p rava-cli --test c2_unsafe` — exit 0 (7 tests).

**Delivered.**
- `sun.misc.Unsafe` U0 is served — `getUnsafe`, `allocateInstance`, a no-op `invokeCleaner`, the jdk initialization queries — and every served call is logged.
- Reflection exposes VM-installed statics (`theUnsafe`); `allocateDirect` returns a `DirectByteBuffer` shape with no storage.

**Boundary.**
- U1–U4, address and layout fidelity, `ReflectionFactory` and buffer storage remain later work.

See [`dynamic-code.md`](../explanation/dynamic-code.md).

## M3.6 — Unmodified Spring CGLIB enhancement and Objenesis instantiation — 2026-11-25
